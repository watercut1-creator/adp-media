# adp-media

Публичный хостинг картинок для карточек ADP на маркетплейсах.

Зачем: Ozon принимает картинки только по ссылке — метод загрузки фото берёт
публичный URL и скачивает файл сам. Этот репозиторий и есть такой источник ссылок.

Что здесь лежит:

- `covers/<артикул>_<8 знаков sha1>.jpg` — готовые обложки, JPEG, 1254×1254.
  Имя файла содержит отпечаток содержимого, поэтому новая версия обложки —
  это всегда новое имя файла, и кэш маркетплейса не отдаёт старую картинку.

Чего здесь НЕТ и не будет: кода, данных, ключей, автоматических запусков
(GitHub Actions). Файлы заливаются вручную из рабочего репозитория.

Ссылка на файл (открывается без входа в GitHub):
`https://raw.githubusercontent.com/watercut1-creator/adp-media/main/covers/<имя файла>`
